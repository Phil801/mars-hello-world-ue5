# Archived astronaut radio-processed takes

These three WAV files were the first astronaut voice pack, processed as
band-limited radio comms (high-pass, low-pass, cabin echo). They were retired
(not deleted) when the astronaut was switched to a natural human voice
(Piper LibriTTS-R speaker 199, loudness normalisation only) and the victory
line was updated to "I hate it when things call me Kevin. I go by Kev."

Live lines are in `RawAudio/VO_Astronaut_*.wav`. This folder is not imported
by `Content/Python/mars_setup.py`.
