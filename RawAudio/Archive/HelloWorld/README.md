# Archived hello-world voice lines

These three WAV files were the original one-line greetings shipped with the first
commit of Mars Hello World:

- `VO_Martian_HelloWorld.wav` — "Hello, world!" (Piper LibriTTS-R speaker 700)
- `VO_XBot_HelloWorld.wav` — "Hello, world." (speaker 333)
- `VO_Venusian_HelloWorld.wav` — "Hello, world!" (speaker 850)

They were retired (not deleted) when the show was rewritten around the hunt for
Kevin. The live lines now live in `RawAudio/VO_<Species>_<LineId>.wav` and are
generated by `Tools/voice/generate_voices.py`. This folder is not imported by
`Content/Python/mars_setup.py`.
